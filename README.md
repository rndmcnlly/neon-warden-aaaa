# Neon Warden AAAA

A deliberately over-produced 3D vertical slice of _Neon Warden_, the small
Phaser shmup written as a course starter, rebuilt in three.js and TypeScript
by Adam Smith and coupled agents. It is a parked teaching artifact: read the
source, the dated `research/` notes and the history to see how an agentic
production went, honestly.

## Run it

Install [Deno](https://deno.com), then:

```sh
deno task dev   # local dev server on http://localhost:3000
deno task ci    # format, lint, type check, tests, production build
```

No local models, paid APIs or ffmpeg are needed: generated assets are
committed. See `docs/REGENERATION.md` for how each was made and why rerunning
a generator makes a new asset, not the shipped one.

## Hosting

`.github/workflows/pages.yml` runs `deno task ci` with `REPO_NAME` set to the
repository name (so `vite.config.ts` builds under `/<repo>/`) and deploys
`dist/` to GitHub Pages. A multi-page restructure of the build (landing page at
the root, game at `/play/`) was in progress when the workflow was written:
re-check the workflow's artifact path and the service worker scope once it
lands.

  terms that grant commercial use of outputs. These are not reproducible (no
