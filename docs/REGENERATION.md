# Regenerating assets

This project is parked (see `AGENTS.md`, Lifecycle). **The committed outputs
are the canonical artifacts.** A fresh clone builds and runs with nothing but
Deno: `deno task ci` needs no local models, no paid APIs, no ffmpeg and no
`vo/out` WAVs. Regeneration is documented so a reader can see how each asset
was made, not because anyone is expected to redo it. Several generators need
model weights that are not in the repository, Apple Silicon, or money, and
several outputs were picked by a person from candidates. Rerunning a generator
gives you a new asset, not the shipped one.

## If you do want to regenerate

- Treat it as making a variant. Keep the shipped file until the new one has
  been heard or seen in context (`docs/SKILLS.md`, asset audition).
- Model weights and paid keys are named only by environment variable
  (`VO_MODELS_DIR`, `SA3_DIR`, `FAL_KEY`, `OPENROUTER_API_KEY`); the defaults
  point inside the repository folders, where nothing is committed, so a
  missing model fails loudly instead of finding something on the author's
  machine.
- Log any paid call in `research/SPEND.md`.
