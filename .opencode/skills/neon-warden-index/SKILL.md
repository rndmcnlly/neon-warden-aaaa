Project-owned domestic guidance, not a global installation. Load only the matching
specialist by exact ID. Paths in these skills are repository-root-relative.

| Intent                                                                                                | Load                                  |
| ----------------------------------------------------------------------------------------------------- | ------------------------------------- |

CLIs and READMEs own operational detail; these skills own selection and judgment.
